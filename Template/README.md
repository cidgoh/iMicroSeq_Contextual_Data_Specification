# iMicroSeq Data Collection Template

This folder relates to the implementation of the **iMicroSeq contextual data specification**, which has been developed based on findings from the needs assessment. The specification defines the core data fields and controlled terms required to support interoperable data capture for water-based microbial genomics.

The full set of fields, definitions, and terms that comprise the specification are described in the **Reference Guide**.

## Accessing Templates
This specification is designed to be used with the DataHarmonizer application.

### During testing
For the current testing round, the iMicroSeq template is available in this folder as a ready-to-use copy of the DataHarmonizer:

1. Download [`DataHarmonizer.zip`](https://github.com/cidgoh/iMicroSeq_Contextual_Data_Specification/raw/main/Template/DataHarmonizer.zip) from this folder.
2. Unzip the whole file.
3. Open the unzipped folder, go to `web` > `dist`, and double-click `index.html`. The DataHarmonizer opens in your web browser and runs locally, so nothing you enter is uploaded.
4. Check the template box at the top reads **iMicroSeq**. If it does not, select it from the drop-down (or **File > Change Template**).

Testers should follow the full instructions in the [Testing](https://github.com/cidgoh/iMicroSeq_Contextual_Data_Specification/tree/main/Testing) folder.

### After testing
Once testing is complete, the iMicroSeq template will be added to the [Pathogen Genomics Package (PGP)](https://github.com/cidgoh/pathogen-genomics-package) and this download will be retired. From then on, please use the most recent PGP release.

Alternatively, users can create their own templates using the fields and controlled vocabularies defined in the Reference Guide.
