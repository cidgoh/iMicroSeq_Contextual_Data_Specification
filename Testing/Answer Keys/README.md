# Answer Keys

Completed versions of the three worked example scenarios used in **Part B** of the testing instructions, plus a blank template.

**Don't open an answer key until you have curated that scenario yourself.** Each key is one reasonable way to curate the scenario, not the only one. If you think your answer is better, tell us in the [feedback form](https://forms.gle/tQaS8h7wcqxSaghE6).

All content is fictional: projects, organisations, people, sites, coordinates and results are invented and labelled as such.

## Files

| File | Scenario | Records |
|---|---|---|
| `iMicroSeq_AnswerKey_S1_Municipal-Wastewater_v1.2.xlsx` | Municipal wastewater treatment plant influent | 4 |
| `iMicroSeq_AnswerKey_S2_Drinking-Source-Water_v1.2.xlsx` | Source and drinking water, community-triggered monitoring | 3 |
| `iMicroSeq_AnswerKey_S3_Leachate-Mining-AMR_v1.2.xlsx` | Landfill leachate and mining-influenced water, AMR metagenomics | 3 |
| `iMicroSeq_Blank-Template_v1.2.xlsx` | Empty template, plus a **Field guide** sheet listing every field with its requirement level, permitted values, definition and example | - |

## Inside each answer key

- **Answer Key (FICTIONAL)**: the completed records, colour-coded yellow (required), purple (recommended) and white (optional). Compare against this sheet.
- **DH_import**: the same records with a single header row. Open this in the DataHarmonizer with **File > Open** if you want to view the key there.
- **Scenario (FICTIONAL)**: the scenario narrative and what it is testing.

All files match iMicroSeq specification v1.0 (155 fields: 13 required, 48 recommended, 94 optional).
